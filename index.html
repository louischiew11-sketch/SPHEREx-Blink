Data: SPHEREx Quick Release spectral images from NASA/IPAC IRSA, cut out around each target and re-aligned onto one shared sky grid (north up, east left, 6.15″ pixels). Each frame is one exposure, so the wavelength at a given pixel changes from frame to frame; the readout under the image shows it. Brightness is shown above each frame’s own background, because the files still contain zodiacal light.

To add data: download new cutouts, run python spx_convert.py new/*.fits --name "WISE 0855" --merge, then upload the updated spherex-data.json next to this page.
